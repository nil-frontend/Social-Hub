# Plan 01-03: App Shell Layout & Navigation

## Objective
Implement the top-level application shell adhering to Apple web ergonomics: an ultra-thin 44px global navigation header, frosted sub-nav bar, and a responsive creator dashboard layout with empty-state routing.

## Context
- Reference: `DESIGN.md` section "Top Navigation" (`global-nav` 44px, `sub-nav-frosted` 52px).
- Routes to scaffold:
  - `/` (Hero / Welcome landing)
  - `/dashboard` (Overview & quick stats)
  - `/channels` (Connected social accounts)
  - `/upload` (Video distribution creator)
  - `/history` (Publishing activity & logs)

## Tasks

- [ ] **Task 1: Build `GlobalNav` Header**
  - 44px height, `#000000` deep black background.
  - Centered brand title ("Social-Hub"), subtle links with 12px SF Pro typography.
  - Right-aligned auth action pill button ("Sign In" / Profile avatar).

- [ ] **Task 2: Build `SubNavFrosted` Header**
  - 52px height, sticky top (`top-0 z-40`), `backdrop-blur-md bg-[#f5f5f7]/80` with 1px hairline bottom separator.
  - Displays current section title (e.g. "Connected Channels", "Distribute Video") on the left and quick action CTA on the right.

- [ ] **Task 3: Build Dashboard Shell with Sidebar**
  - Responsive layout: collapsible desktop sidebar + mobile drawer.
  - Clean icons from `lucide-react` for Navigation items:
    - Dashboard (`LayoutDashboard`)
    - Channels (`Share2` / `Tv`)
    - Distribute (`UploadCloud`)
    - History (`History` / `Clock`)
  - Active navigation state indicator matching Apple pill aesthetic.

- [ ] **Task 4: Scaffold Placeholder Pages**
  - Wire up `/dashboard`, `/channels`, `/upload`, and `/history` with Apple-styled empty-state cards and titles, ready for Phase 2 (Supabase Auth & Database) integration.

## Verification Criteria
- [ ] Smooth navigation between `/dashboard`, `/channels`, `/upload`, and `/history`.
- [ ] Frosted glass effect functions properly during scrolling.
- [ ] Fully responsive on mobile viewport (≤ 640px) and desktop (≥ 1024px).
- [ ] `npm run build` compiles without errors.
