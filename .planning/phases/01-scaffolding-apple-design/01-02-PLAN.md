# Plan 01-02: Apple Design System Token Integration & Reusable Components

## Objective
Configure Tailwind CSS with the Apple design tokens specified in `DESIGN.md` and construct reusable UI components (Pill Buttons, Hairline Cards, Apple Inputs, Status Chips) conforming strictly to Apple's Human Interface Guidelines.

## Context
- Reference specification: [DESIGN.md](file:///p:/antygravity-projects/Social-Hub/DESIGN.md).
- Visual standard: Action Blue `#0066cc`, Canvas `#ffffff`, Parchment `#f5f5f7`, Near-black `#1d1d1f`, 17px body copy, negative headline tracking, active scale micro-interactions.

## Tasks

- [ ] **Task 1: Configure Tailwind CSS Theme with Apple Tokens**
  - Extend Tailwind configuration with:
    - Colors: `apple-blue: #0066cc`, `apple-blue-hover: #0071e3`, `apple-blue-dark: #2997ff`, `apple-ink: #1d1d1f`, `apple-parchment: #f5f5f7`, `apple-pearl: #fafafc`, `apple-hairline: #e0e0e0`, `apple-divider: #f0f0f0`, `apple-tile-dark: #272729`.
    - Font Family: SF Pro Display/Text system stack.
    - Letter Spacing: Negative display tracking (`-0.02em` to `-0.01em`).
    - Shadows: Only Apple's signature soft product shadow `0 3px 20px rgba(0, 0, 0, 0.08)`.

- [ ] **Task 2: Build `AppleButton` Component**
  - Implement variants:
    - `primary`: Full pill (`rounded-full`), Action Blue background, white text.
    - `secondary`: Ghost pill (`rounded-full`), white background, Action Blue text and hairline border.
    - `utility-dark`: Compact rect (`rounded-lg`), Ink background (`#1d1d1f`), white text.
    - `ghost`: Transparent with subtle hover state.
  - Enforce `active:scale-95 transition-transform duration-100 ease-out` on all interactive states.

- [ ] **Task 3: Build `AppleCard` & `Tile` Components**
  - Implement variants:
    - `canvas`: Pure white surface with 1px hairline border and `rounded-2xl` corners.
    - `parchment`: `#f5f5f7` surface for alternating sections.
    - `dark`: `#272729` tile with white text.

- [ ] **Task 4: Build `AppleInput` & `AppleTextarea` Components**
  - Pill search input (`rounded-full`) and modern form inputs (`rounded-xl`).
  - Subtle hairline borders with 2px Action Blue focus ring (`focus:border-[#0071e3] focus:ring-2 focus:ring-[#0071e3]/20`).

- [ ] **Task 5: Build `AppleBadge` & `StatusChip`**
  - Translucent pill chips for platform tags (`YouTube`, `Facebook`, `Instagram`) and publishing status badges (`Draft`, `Uploading`, `Published`, `Scheduled`, `Failed`).

## Verification Criteria
- [ ] Component catalog test file renders all variants cleanly without hydration or styling bugs.
- [ ] Active micro-interaction (`scale-95`) triggers on button clicks.
- [ ] Colors match `DESIGN.md` hex values exactly.
