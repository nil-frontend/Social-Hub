# Plan 01-01: Next.js 15 Project Scaffolding & Dependencies

## Objective
Initialize the Next.js 15 App Router project in `p:\antygravity-projects\Social-Hub` with TypeScript, ESLint, Tailwind CSS, Lucide icons, and utility libraries, while establishing clean environment variable definitions.

## Context
- Workspace is currently a clean Git repository with `DESIGN.md` and `.planning/`.
- Target framework: Next.js 15 with App Router in `src/` directory.

## Tasks

- [ ] **Task 1: Scaffold Next.js Project**
  - Initialize Next.js 15 with TypeScript, Tailwind CSS, ESLint, App Router, and `src/` directory structure.
  - Retain `DESIGN.md`, `.planning/`, and `docs/`.

- [ ] **Task 2: Install Core Dependencies**
  - Install icons and UI utilities:
    `npm install lucide-react clsx tailwind-merge`
  - Install Supabase SSR and client libraries:
    `npm install @supabase/supabase-js @supabase/ssr`

- [ ] **Task 3: Configure Environment Variables**
  - Create `.env.example` with:
    - `NEXT_PUBLIC_SUPABASE_URL`
    - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
    - `SUPABASE_SERVICE_ROLE_KEY`
    - `GOOGLE_CLIENT_ID`
    - `GOOGLE_CLIENT_SECRET`
    - `NEXT_PUBLIC_APP_URL=http://localhost:3000`
  - Create a template `.env.local` for development.

- [ ] **Task 4: Setup Utility Helpers**
  - Create `src/lib/utils.ts` with `cn()` function combining `clsx` and `tailwind-merge`.

## Verification Criteria
- [ ] `npm run build` succeeds without TypeScript or ESLint errors.
- [ ] Project runs cleanly on `http://localhost:3000`.
- [ ] `src/lib/utils.ts` is available for component imports.
