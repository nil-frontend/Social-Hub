# Plan 05-03: Video Drafts Persistence & Full Metadata Integration

## Objective
Integrate category selection, rich tag chips, scheduled release picker, and thumbnail auto-attachment into the `UploadWizard` and implement video draft saving in Supabase.

## Context
- Connects to Supabase `video_drafts` table.
- Enables creators to save drafts and resume later.
- Connects thumbnail upload after video stream completion.

## Tasks

- [ ] **Task 1: Build Video Drafts Server Actions**
  - Create `src/app/actions/drafts.ts`:
    - `saveVideoDraft(draftData)`: Saves draft to `video_drafts`.
    - `getVideoDrafts()`: Fetches saved drafts for the user.
    - `deleteVideoDraft(draftId)`: Removes a draft.

- [ ] **Task 2: Update `UploadWizard` Component**
  - Integrate category dropdown from `src/lib/youtube/categories.ts`.
  - Replace raw tag string input with `TagInput` component.
  - Connect `SchedulePicker` for scheduled drops.
  - Wire custom thumbnail upload dispatch to `/api/youtube/thumbnail/set` after video streaming finishes.

## Verification Criteria
- [ ] Creators can select any YouTube category and configure tags and schedules.
- [ ] Thumbnail upload automatically triggers upon video upload completion.
- [ ] `npm run build` succeeds with zero errors.
