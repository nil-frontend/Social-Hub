# Plan 05-01: YouTube Category Dictionary & Custom Thumbnail API Handler

## Objective
Create the YouTube category dictionary and the server route handler for attaching custom thumbnails to uploaded videos via YouTube Data API v3 `thumbnails.set`.

## Context
- Connects with `getValidAccessToken()` from `src/lib/youtube/token-manager.ts`.
- Handles binary image upload (`image/jpeg`, `image/png`) up to 2MB.
- Gracefully handles channels without phone verification.

## Tasks

- [ ] **Task 1: Build YouTube Category Dictionary**
  - Create `src/lib/youtube/categories.ts`:
    - List of YouTube categories with `id` and `label`.
    - Helper `getCategoryName(id: string): string`.

- [ ] **Task 2: Build Thumbnail Upload Route Handler**
  - Create `src/app/api/youtube/thumbnail/set/route.ts`:
    - Authenticates user and checks channel ownership.
    - Extracts `videoId`, `socialAccountId`, and `thumbnail` file from `FormData`.
    - Obtains fresh access token via `getValidAccessToken(socialAccountId)`.
    - Dispatches binary `POST` to `https://www.googleapis.com/upload/youtube/v3/thumbnails/set?videoId={videoId}`.
    - Handles 403 unverified channel errors with friendly notice.

## Verification Criteria
- [ ] Category list covers all 13 major categories.
- [ ] Route handler correctly uploads image bytes to YouTube and handles verification errors.
