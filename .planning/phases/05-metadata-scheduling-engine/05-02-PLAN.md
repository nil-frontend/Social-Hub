# Plan 05-02: Rich Tag Input & Future Schedule Picker Components

## Objective
Construct interactive Apple-styled UI components for tag keyword chips (with 500-char total counter) and future date/time scheduling.

## Context
- Reference: `DESIGN.md` (Translucent chips, Action Blue focus ring, and clean micro-interactions).
- Enforces YouTube's 500 character limit across all tags combined.

## Tasks

- [ ] **Task 1: Build `TagInput` Component**
  - Create `src/components/upload/tag-input.tsx`:
    - Accepts comma or Enter key to add tags.
    - Renders tags as removable Apple badges with delete button.
    - Shows remaining characters out of 500 total limit.
    - Prevents duplicate tags and auto-trims whitespace.

- [ ] **Task 2: Build `SchedulePicker` Component**
  - Create `src/components/upload/schedule-picker.tsx`:
    - Clean date + time picker.
    - Enforces minimum 15 minutes in the future.
    - Displays user's local timezone and formats human-readable release date.

## Verification Criteria
- [ ] Tag input properly chips on comma and Enter, rejecting inputs over 500 chars total.
- [ ] Schedule picker prevents selecting past times and generates valid ISO 8601 timestamps.
