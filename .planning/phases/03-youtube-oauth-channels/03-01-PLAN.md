# Plan 03-01: Google OAuth 2.0 Handlers & YouTube Profile Fetcher

## Objective
Implement Google OAuth 2.0 authorization endpoints and YouTube Data API v3 profile fetching to allow linking multiple YouTube channels to the authenticated user's workspace.

## Context
- Requires `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` in `.env.local`.
- Uses `encryptToken` from `src/lib/crypto.ts` to secure tokens at rest.
- Supports linking multiple channels by passing `prompt=consent select_account`.

## Tasks

- [ ] **Task 1: Build YouTube OAuth Helper**
  - Create `src/lib/youtube/oauth.ts`:
    - `getGoogleAuthUrl(userId: string)`: Generates Google OAuth URL with CSRF state token.
    - `exchangeCodeForTokens(code: string)`: Exchanges authorization code for tokens.
    - `fetchChannelProfile(accessToken: string)`: Calls `youtube.channels.list(part="snippet,statistics", mine=true)`.

- [ ] **Task 2: Build Connect Route Handler**
  - Create `src/app/api/auth/youtube/connect/route.ts`:
    - Verifies user authentication via Supabase.
    - Sets CSRF state cookie and redirects browser to Google OAuth consent screen.

- [ ] **Task 3: Build Callback Route Handler**
  - Create `src/app/api/auth/youtube/callback/route.ts`:
    - Validates state cookie against callback query param.
    - Exchanges code for tokens.
    - Fetches channel profile (Title, Channel ID, Avatar, Subscribers).
    - Encrypts tokens using `encryptToken()`.
    - Inserts or updates channel record in `social_accounts` table.
    - Redirects to `/channels?success=channel_connected`.

## Verification Criteria
- [ ] Connect and callback routes compile cleanly without type errors.
- [ ] State validation prevents CSRF attacks.
- [ ] Upsert handling safely supports re-authenticating the same channel or adding new ones.
