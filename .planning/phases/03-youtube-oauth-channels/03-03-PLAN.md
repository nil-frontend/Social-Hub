# Plan 03-03: Apple-Styled Connected Channels Dashboard & Live Metrics

## Objective
Implement the user interface for `/channels` showcasing connected YouTube channels with Apple design standards (custom channel cards, avatar renders, subscriber count badges, disconnect action) and update `/dashboard` with live channel counts.

## Context
- Reference: `DESIGN.md` (Product cards, Action Blue pills, parchment surfaces, and hairline borders).
- Live data from Supabase `social_accounts` table.

## Tasks

- [ ] **Task 1: Build Connected Channels View**
  - Update `src/app/channels/page.tsx`:
    - Renders grid of connected channels.
    - Each channel card displays:
      - Channel Avatar image.
      - Channel Title and Handle (`@customUrl`).
      - Subscriber count pill badge (`AppleBadge`).
      - Active/Inactive toggle.
      - Disconnect button with confirmation dialog.
    - "Connect YouTube Channel" pill button at top right and in empty state.
    - Setup banner warning if `GOOGLE_CLIENT_ID` is not yet configured in `.env.local` with link to `docs/GOOGLE_CLOUD_SETUP_GUIDE.md`.

- [ ] **Task 2: Build Channel Card Component**
  - Create `src/components/channels/channel-card.tsx` with optimistic UI for disconnect and status toggle.

- [ ] **Task 3: Update Dashboard Live Metrics**
  - Update `src/app/dashboard/page.tsx` to read actual channel count from `social_accounts` for the logged-in user.

## Verification Criteria
- [ ] Seamlessly renders multiple connected channels without layout breaking.
- [ ] Disconnect action properly removes channel and updates UI.
- [ ] `npm run build` succeeds with zero errors.
