# Plan 03-02: Automated Token Refresh Engine & Channel Management Server Actions

## Objective
Build the automated YouTube OAuth access token refresh engine and server actions to disconnect channels or toggle active status.

## Context
- Google access tokens expire after 1 hour (3600 seconds).
- The token manager must detect imminent expiration and transparently refresh tokens before video upload operations.

## Tasks

- [ ] **Task 1: Build Token Manager**
  - Create `src/lib/youtube/token-manager.ts`:
    - `getValidAccessToken(socialAccountId: string)`:
      - Reads channel from `social_accounts`.
      - Decrypts access and refresh tokens.
      - If `token_expires_at` is in the past (or within 5 minutes of expiring), executes token refresh via `https://oauth2.googleapis.com/token`.
      - Updates database with newly encrypted access token and fresh expiration timestamp.
      - Returns valid plaintext access token for immediate API use.

- [ ] **Task 2: Build Channel Server Actions**
  - Create `src/app/actions/channels.ts`:
    - `getConnectedChannels()`: Fetches all channels for current user ordered by connected date.
    - `disconnectChannel(channelId: string)`: Deletes channel from `social_accounts`.
    - `toggleChannelActive(channelId: string, isActive: boolean)`: Toggles active status.

## Verification Criteria
- [ ] Token refresh logic handles edge cases (missing refresh token, network timeout).
- [ ] RLS ensures users can only query and mutate their own channels.
