# Plan 06-01: Multi-Channel Dispatch Engine & Task Persistence Server Actions

## Objective
Implement server actions for creating and updating publishing tasks in Supabase and construct the client-side orchestrator that dispatches resumable uploads across multiple selected YouTube channels.

## Context
- Connects `ResumableUploader` from `src/lib/youtube/resumable-uploader.ts`.
- Updates `publish_tasks` table in Supabase.
- Dispatches custom thumbnails via `/api/youtube/thumbnail/set`.

## Tasks

- [ ] **Task 1: Build Publish Tasks Server Actions**
  - Create `src/app/actions/tasks.ts`:
    - `createPublishTasks(draftId, channelIds)`: Inserts pending task records in `publish_tasks`.
    - `updatePublishTask(taskId, update)`: Updates progress, videoId, status, and completion timestamp.
    - `getPublishHistory()`: Fetches all publishing tasks with joined channel details for the current user.

- [ ] **Task 2: Build Multi-Channel Dispatcher**
  - Create `src/lib/youtube/dispatcher.ts`:
    - Method `dispatchMultiChannelUpload(config)`:
      - Iterates through selected channels.
      - Requests upload session from `/api/youtube/upload/initiate`.
      - Streams video chunks with per-channel progress callbacks.
      - Dispatches thumbnail if provided.
      - Updates task records in Supabase.
      - Returns aggregated results per channel.

## Verification Criteria
- [ ] Concurrently handles uploads to multiple channels without state crosstalk.
- [ ] Correctly records task records in Supabase with RLS verification.
