# Plan 06-02: Real-Time Upload Progress Modal & Per-Channel Telemetry

## Objective
Build the Apple-styled live progress modal displaying real-time upload percentage, transfer speed, thumbnail attachment state, and clickable YouTube watch links for each target channel.

## Context
- Reference: `DESIGN.md` (Translucent backdrop blur, capsule pills, Action Blue progress bar, and active micro-interactions).
- Provides immediate visual feedback during multi-channel publishing.

## Tasks

- [ ] **Task 1: Build `UploadProgressModal` Component**
  - Create `src/components/upload/upload-progress-modal.tsx`:
    - Fullscreen frosted backdrop (`backdrop-blur-md bg-black/40`).
    - Centered card showing video title and overall progress.
    - Per-channel progress rows with:
      - Channel avatar and name.
      - Action Blue progress bar with smooth transition.
      - Live percentage and speed readout.
      - Success state: Emerald checkmark and clickable "Watch on YouTube" pill link.
      - Error state: Rose warning with error details.
    - Close / Done button enabled upon completion.

- [ ] **Task 2: Connect Progress Modal to `UploadWizard`**
  - Wire the "Distribute to N Channels" submit button to launch the dispatch engine and open `UploadProgressModal`.

## Verification Criteria
- [ ] Progress bars smoothly reflect byte transfers during active upload.
- [ ] Watch links open the correct YouTube video URL (`https://youtu.be/{videoId}`).
