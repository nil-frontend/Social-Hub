# Plan 06-03: Publishing History View, Dashboard Metrics & Final Verification

## Objective
Implement the live activity and publishing history dashboard on `/history` with filterable task lists, channel badges, and watch links, update `/dashboard` with real-time stats, and verify the entire platform end-to-end.

## Context
- Live data from `publish_tasks` joined with `social_accounts` in Supabase.
- Final step in Milestone 1 (V1).

## Tasks

- [ ] **Task 1: Build Publishing History View**
  - Update `src/app/history/page.tsx`:
    - Fetches live tasks via `getPublishHistory()`.
    - Renders activity list with:
      - Video Title & Thumbnail.
      - Destination Channel Avatar & Name.
      - Status badge (`Published`, `Scheduled`, `Uploading`, `Failed`).
      - Publish date/time.
      - Direct clickable YouTube link (`https://youtu.be/{videoId}`).
    - Empty state when no distribution history exists.

- [ ] **Task 2: Update Overview Dashboard Metrics**
  - Update `src/app/dashboard/page.tsx`:
    - "Total Published" displays true count of published tasks.
    - "Scheduled Queue" displays count of pending scheduled tasks.
    - Recent distribution activity card.

- [ ] **Task 3: Production Build & Full Verification**
  - Run full `npm run build` and ensure zero errors across all routes.

## Verification Criteria
- [ ] `/history` displays real tasks with correct timestamps and links.
- [ ] Overview dashboard metrics accurately reflect Supabase database state.
- [ ] `npm run build` compiles without errors.
