# Plan 04-03: Apple-Styled Drag-and-Drop Video Uploader & Media Preview

## Objective
Build the client-side drag-and-drop video file uploader component with instant format validation, video preview playback, file metrics, and custom thumbnail selection adhering to Apple design principles.

## Context
- Reference: `DESIGN.md` (Parchment surfaces, subtle hairline borders, rounded-2xl containers, and pill buttons).
- Supports MP4, MOV, and WebM files up to 1GB.
- Supports JPEG/PNG custom thumbnails up to 2MB.

## Tasks

- [ ] **Task 1: Build `VideoDropzone` Component**
  - Create `src/components/upload/video-dropzone.tsx`:
    - Drag-and-drop dropzone with active drag hover animations.
    - File validation: Format (`mp4`, `mov`, `webm`) and size check (≤ 1GB).
    - Integrated `<video>` preview player with play/pause, duration, and resolution detection.
    - File info badge (Name, Size, Type) with "Replace Video" and "Remove" actions.

- [ ] **Task 2: Build `ThumbnailPicker` Component**
  - Create `src/components/upload/thumbnail-picker.tsx`:
    - Image file selector for custom 16:9 thumbnails.
    - Image preview with aspect ratio cropping guide.
    - Remove / replace action.

- [ ] **Task 3: Integrate Dropzone into Distribute Page**
  - Update `src/app/upload/page.tsx` with live `VideoDropzone` and `ThumbnailPicker`.

## Verification Criteria
- [ ] Drag-and-drop rejects unsupported formats with clean Apple-styled error alert.
- [ ] Video preview renders smoothly in browser without memory leaks (revoking ObjectURL on unmount).
- [ ] `npm run build` succeeds with zero errors.
