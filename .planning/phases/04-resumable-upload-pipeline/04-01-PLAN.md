# Plan 04-01: Resumable Upload Session Initialization API Handlers

## Objective
Implement the server-side route handler that authorizes and initiates a Google YouTube Resumable Upload session for a selected connected channel, returning the direct upload session URI to the browser.

## Context
- Connects with `getValidAccessToken()` from `src/lib/youtube/token-manager.ts` to ensure unexpired credentials.
- Calls `POST https://www.googleapis.com/upload/youtube/v3/videos?uploadType=resumable&part=snippet,status`.
- Supports YouTube metadata and `status.publishAt` ISO timestamp when scheduled.

## Tasks

- [ ] **Task 1: Build Session Initiation Route Handler**
  - Create `src/app/api/youtube/upload/initiate/route.ts`:
    - Authenticates user via Supabase.
    - Validates request payload (`socialAccountId`, `title`, `description`, `privacyStatus`, `madeForKids`, `tags`, `fileSize`, `mimeType`).
    - Obtains fresh access token via `getValidAccessToken(socialAccountId)`.
    - Initiates resumable upload with YouTube Data API v3.
    - Extracts and returns `uploadUrl` from response `Location` header.

## Verification Criteria
- [ ] Route handler properly validates request inputs and returns 400 for invalid data.
- [ ] Returns Google's session URI upon successful initiation.
- [ ] Handles Google API error responses with descriptive messages.
