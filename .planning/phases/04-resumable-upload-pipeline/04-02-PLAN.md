# Plan 04-02: Client-Side Direct-to-YouTube Resumable Streaming Engine

## Objective
Construct the browser-side resumable upload streaming utility that uploads video files directly to Google's session URI with byte-level progress reporting, pause/resume capability, and error recovery.

## Context
- Runs in the browser using `XMLHttpRequest` for native upload progress events.
- Emits byte metrics (`loaded`, `total`, `percentage`, `speed`).
- Returns the final YouTube video ID and watch URL upon completion.

## Tasks

- [ ] **Task 1: Build `ResumableUploader` Client Class**
  - Create `src/lib/youtube/resumable-uploader.ts`:
    - Method `upload(file: File, uploadUrl: string, onProgress: ProgressCallback)`:
      - Streams video file directly to Google session URI via HTTP `PUT`.
      - Tracks real-time upload speed and percentage.
      - Resolves with `{ videoId: string, videoUrl: string }`.
    - Method `resume(file: File, uploadUrl: string)`:
      - Sends query header `Content-Range: bytes */{total}` to find uploaded byte offset on network disconnect.
      - Slices file and continues streaming.
    - Method `abort()`:
      - Cancels ongoing upload cleanly.

## Verification Criteria
- [ ] Streaming engine handles network drops and reports progress accurately.
- [ ] Parses Google's video resource response and outputs valid YouTube video ID.
