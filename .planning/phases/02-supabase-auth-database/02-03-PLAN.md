# Plan 02-03: Apple-Styled Auth UI & Navigation Integration

## Objective
Construct the user authentication interface (`/login` with Sign In and Sign Up modes) styled according to Apple Design System standards, integrating live Supabase Auth actions and updating top navigation with user state.

## Context
- Reference: `DESIGN.md` (Parchment canvas, crisp SF Pro typography, Action Blue pill button).
- Supports Email & Password sign-up/login.

## Tasks

- [ ] **Task 1: Build Server Actions for Auth**
  - Create `src/app/actions/auth.ts`:
    - `signInWithEmail(email, password)`
    - `signUpWithEmail(email, password)`
    - `signOut()`
    - `getCurrentUser()`

- [ ] **Task 2: Build Auth Page (`/login`)**
  - Implement Apple-styled login card:
    - Mode toggle: "Sign In" / "Create Account".
    - `AppleInput` for Email and Password with clean error states.
    - `AppleButton` primary pill with loading state.
    - Informative feedback upon sign-up (e.g. check email confirmation if configured).

- [ ] **Task 3: Integrate User State in GlobalNav**
  - Update `GlobalNav` to dynamically display:
    - "Sign In" button when unauthenticated.
    - User email badge, "Dashboard" link, and "Sign Out" button when authenticated.

- [ ] **Task 4: Build Auth Callback Handler**
  - Create `src/app/auth/callback/route.ts` to handle Supabase email confirmation code exchange.

## Verification Criteria
- [ ] `/login` renders with Apple design aesthetics and handles sign-in/sign-up errors gracefully.
- [ ] `GlobalNav` reflects auth state dynamically.
- [ ] `npm run build` succeeds with zero errors across all auth routes.
